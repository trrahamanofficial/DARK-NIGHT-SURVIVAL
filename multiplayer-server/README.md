# Multiplayer Server

This directory is reserved for the authoritative 1–4 player co-op service.

Requirements before co-op is advertised as playable:
- Server-authoritative movement, combat and session state.
- Room creation/joining, reconnect and disconnect handling.
- Input validation and basic anti-cheat protections.
- Rate limits, logging and deployment cost review.
- Dedicated network tests with multiple real clients.

A database or static website host alone is not a real-time authoritative game server.

Status: architecture placeholder only; server implementation and deployment are scheduled for a later stage.
