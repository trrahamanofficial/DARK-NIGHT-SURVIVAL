# Stage 9 — Additional Maps

## Implemented first pass
- Added an offline map-selection manager with saved selection.
- Added a Change Map action to the pause menu.
- Retained Dark Forest as the default map.
- Added Abandoned Hospital with a perimeter, room dividers, beds, reception area and cold interior lights.
- Added Old Village with six hut structures, doors, a central square, well, church and lantern lighting.
- Added Underground Bunker with reinforced perimeter walls, corridor partitions, crates, consoles and emergency lights.
- Existing player controls, enemies, pickups, inventory and pause flow are reused across locations.
- Story objective markers are currently enabled only on Dark Forest; map-specific story missions are not implemented yet.

## Remaining

- More detailed environmental art, props, collision and navigation tuning.
- Map-specific enemy placement and balancing.
