# Development roadmap

## V0.1 — Offline forest prototype
- [x] Godot project foundation
- [x] First-person movement and mouse look
- [x] Flashlight
- [x] Procedural dark forest and basic monster wander/chase behavior
- [ ] Import into Godot and validate on a real device
- [ ] Add Android touch joystick and look controls

## V0.2 — Survival loop
- Health, stamina, damage and restart flow
- Inventory and collectible resources
- Footstep / ambience / monster audio assets
- Main menu, pause menu and settings
- Offline save slots

## V0.3 — Story content
- Dark Forest objectives and escape sequence
- Abandoned Hospital, Old Village and Underground Bunker
- Monster variants and mission scripting

## V0.4 — Platforms
- Android performance and touch UX
- Windows export and input polish
- Separate Web export with reduced rendering cost

## V0.5 — Online co-op
- Dedicated authoritative multiplayer server
- 1–4 player session flow, reconnect and anti-cheat basics
- Network tests and deployment budget review

## V1.0 — Release preparation
- Accessibility, QA, device compatibility and crash testing
- Protected admin tools; never expose privileged credentials in the game client
- Ads remain disabled until the owner explicitly chooses to enable them
